Questions every student asks

School teaches the how. We show the where.

“Why do I need to learn about rotation?”

Because it keeps a drone level. A gyroscope measures spin, and software uses it to correct the tilt many times a second.

“What is statistics actually for?”

To tell a good sensor from a noisy one. It measures how scattered the readings are, which decides how much to trust each one.

“What is trigonometry for?”

Working out a robot's tilt. Sine and cosine help turn sensor readings into an angle the robot can act on.

PROGRAM 1 · CLASSES 5–7

Science in Motion

Start with the basics of science and discover how electricity, motion and sensors come together to make robots work. Through guided experiments and hands-on building, students progress from curious beginners to confident young makers.

What your child will learn
  • Explore the basics of electricity — understand batteries, switches, circuits and how electrical energy powers devices.
  • Discover motion and forces — learn how motors create movement and how force affects a robot's speed and direction.
  • Get to know robot components — explore motors, wheels, sensors and other essential parts and understand what each one does.
  • Build a first robot — assemble a simple robot and discover how its components work together.
  • Take the first steps in coding — use visual block coding to give a robot instructions, step by step.
  • Make the robot sense and react — use sensors to follow a line, detect obstacles and respond to its surroundings.
  • Experiment, test and improve — make observations, take measurements, troubleshoot problems and improve how the robot performs.
  • Complete a hands-on project — demonstrate a working robot and explain the science behind how it works.
How they learn to code

Start with beginner-friendly visual block coding and gradually progress to writing simple Python programs as confidence grows.

No prior robotics or coding experience needed. Just curiosity, creativity and a willingness to experiment.

PROGRAM 2 · CLASSES 8–10

Robotics and Autonomous Systems

Take school maths and physics beyond the textbook. Learn how sensors measure motion, how code makes decisions and how feedback helps robots balance, move and navigate independently.

What your child will learn
  • Understand the electronics behind robots — explore microcontrollers, motor drivers and motion sensors, and learn how hardware and software work together.
  • Measure motion in the real world — use accelerometers and gyroscopes to collect data about acceleration, rotation and a robot's orientation.
  • Connect maths to movement — apply speed, ratios, angles, sine and cosine to interpret sensor readings and estimate a robot's tilt.
  • Learn to code with Python — write programs that read sensor data, process measurements and control motors using logic and functions.
  • Discover feedback and control systems — understand the difference between a robot's current state and its target, then tune a feedback controller to improve its response.
  • Build a self-balancing robot — bring physics, sensor measurements, mathematics and control code together to help a two-wheeled robot stay upright.
  • Explore autonomous navigation — program a mobile robot to follow a defined course, detect obstacles and make movement decisions with minimal human input.
  • Connect robotics to the real world — discover how similar principles are used in drones, self-driving systems, smartphones and industrial automation.
How they learn to code

Use Python for sensor data, calculations and robot behaviour. Progress to C++ for the robot's real-time control loop, where fast, repeated measurements and motor adjustments help maintain balance.

Questions, answered.

Does this replace school or tuition?

No. It adds to school. We take what your child already studies and show where it works inside real machines.

Which program is right for my child?

Science in Motion is for Classes 5 to 7 and Robotics and Autonomous Systems is for Classes 8 to 10. Not sure? Send an enquiry and we will help you choose.

Does my child need coding experience?

No. Science in Motion starts from zero. Code is introduced step by step, always for a reason: to make something real move or react.
